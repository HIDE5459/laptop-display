仮想ディスプレイ(拡張モード)

作成すると Mac に「2 枚目のモニタ」が追加され、下の一覧に LaptopDisplay という画面が現れます。それを選んで配信すると、 ウィンドウをドラッグして移せる拡張ディスプレイになります。 ミラーリング(複製)でよければ作成せず今の画面を選んでください。
受信側アプリが接続していると、その画面に合う解像度が一覧の先頭に並びます (縦横比が一致するものだけなので黒帯が出ません)。表記は macOS の ディスプレイ設定と同じ考え方で、「スペースを拡大」が既定です。 文字が小さいと感じたら「標準」を、もっと広く使いたければ 「広い」を選んでください。
画面を左右どちらに置くかは「配置を変更」から (システム設定 → ディスプレイ → 配置… で青い四角をドラッグ)。

カーソルの移動

1 回タップで本体 (メイン)、2 回で 2 枚目、3 回で 3 枚目へ移動します。 キー入力を監視するため アクセシビリティの許可が必要です。 左 Option は ⌥+クリック や特殊文字の入力で使うため、 既定は誤爆しにくい右 Option のみです。
判定のため、タップから移動までに約 0.35 秒かかります(連続タップを待つ必要があるため)。

押すたびに次のディスプレイの中央へカーソルが飛び、移動先で一瞬リングが表示されます。 Control+Alt+1 / 2 / 3 で画面を直接指定することもできます(こちらは固定)。
キーの書き方: Control Alt Shift Command を + でつなぎ、最後にキー名 (例: Command+Alt+Right)。単独キーは通常の入力を奪うので避けてください。

Windows 側から Mac を操作する

Windows 側の画面上でタイプ・クリックすると、その操作が Mac に送られます (配信対象が「画面」の場合のみ。ウィンドウ単体の配信では座標が合わないため無効です)。
アクセシビリティの許可が必要です。Windows 側では F9 で送信のオン/オフを切り替えられます。 Alt+Tab など Windows 自身が処理するキーは送れません。

画面収録の権限がありません

拡張ディスプレイとして使う場合は BetterDisplay の仮想ディスプレイを選択してください。 サムネイルが真っ黒な場合は、macOS の「画面収録」権限を LaptopDisplay に許可して再起動してください。
